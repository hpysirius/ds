# DS Ozon 采集助手（Chrome 插件）

用**你自己正常的 Chrome** 采集 Ozon 商品数据，直接上报到 ds 选品系统。

## 为什么不用调试模式了

带 `--remote-debugging-port` 的调试 Chrome 会被 Ozon 风控标记：每次导航都要先过一张
「Antibot Challenge Page」（约 15 秒才放行），慢且经常失败，还会把挑战页标题当商品名写进库。

插件跑在正常浏览器里，用的是你的真实 profile 和登录态 —— 打开速度和你手动访问一样快，
也不会被反爬挑战。

## 安装（一次性）

1. 打开 `chrome://extensions/`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本目录（`extension/ds-collector`）
4. 建议把插件 **固定** 到工具栏（拼图图标 → 图钉）

## 使用

确保 ds 后端在跑（`bash scripts/start.sh`，默认 `http://localhost:3101`）。

### ① 采集列表页（主要用法，批量发现商品）

在任意 Ozon **列表页**上点插件 —— 比如 `/highlight/…`、`/search/…`、类目页：

```
https://www.ozon.ru/highlight/tovary-iz-kitaya-935133/?category=14793&sorting=new
```

- 点 **采集当前列表页**，右侧数字是**往下滚几屏**（Ozon 是无限滚动，实测一屏约 36 个；填 3 大概能拿 100+）
- 抓到的字段：sku、标题、价格、主图、商品链接、评分、评论数
- **库里没有的新商品会自动创建**，已有的则更新（不会把详情页补来的类目/卖家覆盖掉）
- 抓完弹窗会告诉你：抓到多少、新建多少、更新多少

### ② 补详情（给已有商品补类目等）

点 **补详情(批量)**，填数量 → 会把库里「缺类目/主图/价格」的商品逐个打开详情页补齐：
复用同一个标签页，已补上的自动从清单消失，中断后重跑就是断点续跑。

### ③ 采集单个商品页

在商品详情页点 **采集当前商品页**。

### 插件接口

| 接口 | 用途 |
| --- | --- |
| `POST /pricing/extension/products` | 列表页批量上报（新商品自动入库）|
| `GET  /pricing/extension/pending?limit=20` | 拉待补详情清单 |
| `POST /pricing/extension/product-info` | 详情页单条上报 |

## 采哪些字段

标题、品牌、类目路径、价格、主图、评分、评论数、卖家、发货模式（FBS/FBO/rFBS）。

另外：如果你在这个 Chrome 里装了「中实跨境ERP / 闪电采集」并**登录了 Ozon 卖家账号**，
插件会顺带把它渲染的商品卡也读出来 —— 月销、销售额、广告占比(DRR)、加购率、退货取消率、
上架时间等经营指标，一并上报。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | MV3 清单（权限、后台、弹窗） |
| `background.js` | 后台调度：列表抓取+滚动、拉清单、复用标签页、上报、进度 |
| `collector-lib.js` | 页面采集逻辑：`collectProduct` 详情页（JSON-LD→meta→DOM→ERP 插件卡）、`collectList` 列表页（卡片→sku/标题/价格/主图）、`scrollDown` |
| `popup.html` / `popup.js` | 弹窗 UI：连接状态、待补数量、单页/批量采集、进度与日志 |

## 注意

- 后端地址默认 `http://localhost:3101`，可在弹窗里改并保存
- 批量采集时**不要手动关掉那个正在跳商品的标签页**（关了会自动新建一个继续）
- 若商品链接已失效（Ozon 302 到搜索页），插件会自动跳过并记录日志，不会写脏数据
