## 23:xx 修复：新建员工 400 Bad Request + 权限改树结构
- **400 根因**：前端新建员工时 payload 带了 `status`，但 `CreateUserDto` 未声明该字段，而全局 ValidationPipe 开了 `forbidNonWhitelisted` → 报 `property status should not exist`。
  - 修：`CreateUserDto` 增加 `@IsOptional() @IsInt() status?: number`；`users.service.create` 用 `status: dto.status ?? 1`；`UpdateUserDto` 精简为纯 `PartialType(CreateUserDto)`（status 已在基类）。
- **页面权限改树结构**：管理页 `system/users/page.tsx` 把「按分组平铺 Checkbox.Group」改为 antd `Tree`（checkable、defaultExpandAll）。一级=分组（key 前缀 `g:`），二级=页面 key；`onCheck` 里过滤掉 `g:` 前缀，只把真实页面 key 存进 permissions。
- 验证：本地/线上 POST /users 带 status → 201；建号后清理干净，线上仅剩 admin。
