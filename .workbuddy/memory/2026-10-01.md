## 23:23 全站强制登录（前端路由守卫）
- 需求：未登录时所有页面不可用，统一跳登录页。原 /products 等页面未登录也能看（商品接口此前为 @Public）。
- 实现：
  - 新建 `frontend/src/app/login/page.tsx`：全屏登录卡片，登录成功存 ds_token/ds_user 后跳回 `?redirect=` 目标页或 `/`。
  - 改 `frontend/src/components/AppShell.tsx`：client 端读取 localStorage ds_token 作为 authed 状态；未登录且非 /login → `router.replace('/login?redirect=<当前路径>')`，已登录访问 /login → 回 `/`；/login 不渲染后台布局；退出登录 setAuthed(false) 触发跳转。
  - 改 `frontend/src/lib/api.ts`：响应拦截器遇 401 且本地有 token 时清登录态并 `window.location.href='/login'`（兜底 token 过期）。
- 后端未改：登录态由前端守卫控制；后端大量 @Public 接口（含 pricing 列表/导出）因前端登录后始终带 token 仍可用，风险低。
- 验证：本地 `next build` 通过（含 /login 路由）；`deploy.sh` 部署线上 pm2 online；/login 200、/products 200(HTML 由客户端重定向到 /login)、/api/auth/profile 401(正确)。
