## 自采购「落库即自动算出定价」（用户新需求，承接上一条）

需求原话：「我希望在 自采购 的时候，就算出。在1688页面的采集的时候，就直接生成 定价记录里面的数据。」（附「定价记录」列表截图：定价¥ / 跟卖价₽ / 月销量 / 高于跟卖价 / 运费¥ / 采购¥ / 毛利润 / 净利润 / 利润率 / 运费利润比 / 加35% / 重量）

理解：**不再要求手动点「算定价」**——只要记录有「采购成本 + 重量」，落库时就自动跑核价引擎，把物流费 / 定价(¥·₽) / 毛利 / 净利 / 利润率 / 渠道 直接算好写进记录，列表展示与「定价记录」同一套列。**不新建 PricingRecord**（与「跟单比价」仍完全隔离）。

- **关键重构：算价从「前端两遍」搬到后端**。`SelfPurchaseService` 注入 `PricingService`（`SelfPurchaseModule` import `PricingModule`，该模块已 export PricingService）；新增私有 `computePrice(input)`（两遍算价：① `valueRub = 成本×(1+加价率)/汇率` 种子 → 拿定价；② 用①定价当货值收敛；必须带 `includeUnavailable:true`）与 `autoPriceRecord(rec)`。
- **自动算价时机**：`create` / `memo`（插件）/ `update` 三处落库后统一调 `autoPriceRecord`。**已有核价快照（`netProfit != null || shippingFee != null`）则跳过，不覆盖手填/手算结果**。缺成本或缺重量 → 不算（等补齐）。
