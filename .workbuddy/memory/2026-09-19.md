### 关键公式（照搬 Excel，不要自己发明）
```
毛利润 = 定价 − 采购成本 − 国际运费 − 贴单费 − 定价×平台佣金 − 定价×Ozon代理佣金
净利润 = 毛利润 − (采购成本 + 毛利润) × 提现费率
利润率 = 净利润 / 采购成本；运费利润比 = 净利润 / 国际运费；加35% = 定价 / 0.65
反算定价 C = [目标净利 + D·i + (D+E+F)(1−i)] / [(1−g−h)(1−i)]
运费 = 计费重量 × 元/kg + 元/票；XY 走 ROUNDUP(x,2)，GUOO 不取整（保留4位）
```
已用模版样例校验：定价37/运费16 → 毛利润5.265、净利润5.10582、利润率0.6382275；
GUOO 俄罗斯 0.36kg/18×18×10/1000₽ → 13.486 / 17.518 / 21.568，与表内一致。

### 踩到的坑
- `nest start --watch` 会清 `dist`，被 safe-delete 守卫拦下（148 文件 > 50 阈值）。
  改用 `npm run build && npm run start:prod` 起服务。
- 全局 ValidationPipe 开了 `forbidNonWhitelisted`，DTO 必须列全字段；
  `Partial<XxxDto>` 是纯类型、运行时 metatype 变 Object 会跳过校验，
  所以 PATCH 要单独写一个全字段可选的 `UpdateChannelDto`。
- `recompute()` 直接 spread `calcPricing()` 结果会把 grossMargin/netMargin/costTotal
  这些非落库字段塞进 Prisma create 而报错，要显式挑字段。
- Prisma Decimal 返回的是对象，服务层统一用 `num()` 转 number。

## 大改：核价 → 定价工作流（用《9月定价表.xlsx》真实数据校验）

### 真实定价规则（从 9 月定价表反推并逐位校验通过）
```
建议定价 = ceil( (采购成本×(1+加价率) + 国际运费 + 贴单费) / (1 − 平台佣金 − 代理佣金) )
加35%    = 定价 / 0.65（表内显示取整）
```
校验用泡泡机那条真实记录：成本21.8、运费13.21、贴单2、加价10%、佣金12%、代理3.5%
→ 46.38 → 定价 **47**，加35% **72**，毛利 **2.71**，净利 **2.41**，利润率 11%，
运费利润比 18% —— 全部与表内一致。
注意：参与利润计算的是**两位小数后的运费**（表里运费就是手填的两位小数），
否则会差 1 分钱（2.42 vs 2.41）。

### 1688 自动化的边界（重要）
- 1688 图搜结果页是 `search.1688.com/youyuan/index.htm?tab=imageSearch`，
  上传入口靠 `DOM.setFileInputFiles` 塞图；代码里依次尝试 3 个入口 + 多个 file input
- 必须在调试 Chrome 里登录 1688，否则返回明确提示（BadRequest 400，不是 500）
- 插件采集的数据**没有商品主图**，所以以图搜款前先 `sourcing/product-image`
  打开 Ozon 页抓 og:image，并回写 `products.imageUrl`
- 包装信息优先从页面 JSON 里找长宽高/重量，失败再点「包装信息」tab 抓表格；
  抓不到就返回 warnings 让前端提示手填
