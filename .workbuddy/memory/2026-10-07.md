## 闪电采集插件（sd-plugin 3.9.0）域名配置机制分析（2026-10-07 下午）
- 用户拿到竞品「闪电采集」插件（`~/Downloads/sd-plugin-3.9.0`，即闪电ERP的采集工具）问域名怎么配。反编译结论：
  - **配置入口不在 options 页**（options 是空骨架"扩展设置：无配置项"），popup 也只有登录态。配置 UI 在 **Ozon/1688 页面上插件注入的悬浮面板 →「插件配置」→ ERP 站点域名输入框**（content.js 的 `openConfig`→`Vle` 弹窗）。
  - 保存走 background 消息 `saveErpDomainConfig`（`vg()`）：写 `chrome.storage.local[Yn]={manageUrl,originPattern,updatedAt}`，并 `chrome.permissions.request` 请求该 origin 的可选 host 权限（manifest `optional_host_permissions: http(s)://*/*`）。校验 `Hle()`：仅 http/https、自动补 scheme、去尾斜杠。
  - 域名用途：`<manageUrl>/admin-api/ozon/extension/**`（采集上报、listing、利润等全套接口，芋道 admin-api），带 `credentials:"include"` 走浏览器 cookie + token（`check-login`/`forceLiveAuth`）；另按 hostname 调 `/app-api/system/tenant/get-by-website` 解析租户。
  - **未配置时兜底硬编码 `https://ssyk.shanshangnet.com`**；用户租户是 `sczs.shanshangnet.com`（tenant-id 174），不改就对不上租户——这就是官方指南第一步要"配置域名"的原因。另有桌面App模式（`desktopAppUrl`，localhost 时切 `http://127.0.0.1:48080`）。
  - **面板挂载范围（关键）**：`Pce(hostname)` —— controller 面板（含「插件配置」按扭）只在 `ozon.ru`/`www.ozon.ru`/`seller.ozon.ru`/`seller.ozonru.cn` 挂载；buyerFeatures（商品卡挂件）仅 ozon.ru/www.ozon.ru；1688 上是另一套 runtime 采集包、无配置入口。所以 **ERP 站点页（sczs.shanshangnet.com）上永远看不到配置入口**。
  - 存储键：`chrome.storage.local.erpDomainConfig = {manageUrl, originPattern, updatedAt}`；未配置时面板 state.view=`config-required`（直接显示大按扭「插件配置」）。
  - 兜底手段：开 `chrome://extensions` → 该插件 Service Worker「检查视图」console 执行 `chrome.storage.local.get(null)` 查看；或直接发消息 `chrome.runtime.sendMessage({action:'saveErpDomainConfig',manageUrl:'https://sczs.shanshangnet.com'})` 强写。
  - **插件状态全在 `chrome.storage.local`，无 IndexedDB/localStorage**（已 grep 确认）。键清单：`erpDomainConfig`(域名)、`erpAuthCache`/`erpLoginStateCache`/`erpPluginLoggedOut`/`erpAuthCanonicalTabId`/`erpAuthBroadcastEpochV1`(登录态)、`tenantBrandConfig`/`tenantStoreSelectionFences`(租户品牌·店铺)、`ozonProfitConfigCacheV2`(利润配置)、`ozonSellerCookieSnapshotSyncV1`(卖家cookie)、`listingWritebackQueueV1`/`listingPreparationQueueV1`(上架队列)、`selectedStoreInfo`/`selectedStoreId`/`selectedStores`、`desktopAppUrl`/`desktopAppConnected`、`pluginRuntimeDiagnostics`、`OZON_PRODUCT_CURRENT_SELLER_*`(商品卖家缓存)。
  - 清理方式：① 卸载重装（storage 全清）；② Service Worker console `chrome.storage.local.clear()`；③ 精准 `remove([...])`；④ 插件 popup「退出插件登录」只清登录、保留域名。未配域名时报错文案："请先在插件配置中设置站点域名"。
