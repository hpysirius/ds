# 2026-10-06

## 插件下载入口（新增，对标闪电ERP顶栏「下载插件」）

用户诉求：系统里要有个「下载插件」的入口，插件每次更新后都能从这里拿到最新版。

**打包侧**
- 新增 `scripts/pack-extension.sh`：读 `extension/ds-collector/manifest.json` 的版本号 →
  把插件目录打成 zip 到 `frontend/public/plugin/`：
  - `ds-collector.zip`（固定文件名，前端永远指向它，换版本不用改前端代码）
  - `ds-collector-v<version>.zip`（带版本号副本，便于留存/回滚）
  - `plugin-info.json`（name/version/description/size/fileCount/builtAt，前端读它显示版本）
- zip 内顶层目录是 `ds-collector/`，并附带中文 `INSTALL.txt`（安装 / 首次配置 / 更新 / 常见问题）。
- 打包后**自检**：`unzip -p ... manifest.json` 的版本必须等于源码版本，不一致直接报错退出。
- `deploy.sh` 新增 `[1.5/5] 打包浏览器插件` 步骤，每次部署自动重打包 —— 插件改完只管跑 `deploy.sh`。
  线上已验证：部署后 `plugin-info.json` 的 `builtAt` 变成本次部署时间。

**前端侧**
- 新增 `frontend/src/components/PluginDownload.tsx`：
  - `usePluginInfo()` —— `fetch('/plugin/plugin-info.json', {cache:'no-store'})`，失败静默降级。
  - `PluginDownloadButton` —— 顶栏按钮；**有新版本时亮小红点**（对比 localStorage `ds_plugin_downloaded_version`）。
  - `PluginDownloadModal` —— 版本/打包时间/体积 + 下载按钮 + 5 步安装说明；有新版时加一条 Alert 提醒。
  - `PluginInstallSteps` —— 安装步骤，guide 页复用同一份。
  - 下载实现：临时 `<a download>` + URL 带 `?v=<版本>` 破缓存，文件名形如 `DS Ozon 采集助手 v1.6.8.zip`。
- `AppShell.tsx`：Header 右侧 Space 第一位加 `<PluginDownloadButton />`（所有登录用户可见，不走权限）。
- `guide/page.tsx`：hero 下方加「下载浏览器插件」卡片（左：下载按钮+版本信息，右：安装步骤）；
  把「二、开始之前 ①」文案从「选择 `extension/ds-collector` 目录」改成「先下载 zip 再解压加载」（同事没有源码）；
  FAQ 新增「插件有新版了，怎么更新？」。
- `.gitignore` 忽略 `frontend/public/plugin/*.zip` 与 `plugin-info.json`（都是生成物）。

## 踩坑

- `node -e 'script' arg1 arg2` 中 `process.argv = [node, arg1, arg2]`，解构别多跳一位：
  写成 `const [, , src, outDir]` 会把 OUT_DIR 当成 src（报 ENOENT，且因为 src 恰好是输出目录，报错路径很迷惑）。
- **SSR 安全**：Modal 组件函数体里直接读 `localStorage` 会在 Next 预渲染阶段抛 `localStorage is not defined`
  （即使 `open=false` 也会执行函数体）→ 必须放进 `useEffect` 再用 state 渲染。
