## 12:50 顶部栏：图标与店名没对齐（基线对齐坑）
- 反馈：员工顶栏左侧 `🏬 莫斯科一号店`，**图标比店名偏高约 2px**。
- 根因（两层）：
  1. `ShopOutlined` 是 anticon，CSS 自带 `vertical-align: -0.125em`，且**行内元素的基线取自身底边**；而 antd `Tag` 是 inline-block，基线取**内部文字基线**（约距 Tag 顶 13.7px）。两者放在行内流里按基线对齐 → 图标比 Tag 中心高约 2.3px。用 `<Space align="center">` 也救不了：Space 的每个 child 都包一层 `.ant-space-item` div，**基线对齐发生在 item div 内部**，外层 flex 居中只是把「已经错位的两个盒子」居中。
  2. antd `Layout.Header` 自带 `line-height: 64px` 会被子树继承（我们只覆盖了 height:56），超大行高会放大这类基线错位。
- 修复（`frontend/src/components/AppShell.tsx`）：
  - `StoreSwitcher` 两个分支都由 `<Space size={6}>` 改成 `<div style={{display:'flex',alignItems:'center',gap:6}}>`，并给图标 `style={{display:'block',color:'#8c8c8c'}}` —— `display:block` 让图标脱离行内基线体系、直接作为 flex item 被 `align-items:center` 垂直居中（Super 分支的 icon+Select 一样适用）。
  - `Header` style 增加 `lineHeight: 'normal'` 重置继承来的 64px 行高。
- 通用结论：**antd 里「图标 + Tag」并排要用 flex + `align-items:center`，不要用 `Space`/行内流**（Space 的 item 包裹层会保留基线对齐）。
